# Учебный веб-проект.

## Описание проекта.

Данный веб-сайт был создан в рамках практических занятий по веб-разработке. Проект предназначен для изучения основ создания и оформления веб-страниц.

## Основные возможности

- Просмотр главной страницы сайта.
- Переход между разделами.
- Просмотр текстовой информации и изображений.
- Удобное и простое оформление.
- Адаптация сайта под разные размеры экрана.

## Используемые технологии

- **HTML5** — создание структуры сайта.
- **CSS3** — оформление и стилизация страниц.
- **JavaScript** — добавление интерактивных элементов.
- **Git** — контроль версий проекта.
- **GitHub** — хранение и публикация проекта.

## Структура проекта

```text
web-project/
│
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
└── README.md
```

## Запуск проекта

1. Скачать или клонировать репозиторий с GitHub.
2. Открыть папку проекта на компьютере.
3. Найти файл `index.html`.
4. Открыть его в браузере.
